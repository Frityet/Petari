# Ordinary input record

The rabbit and tower scripts used the existing debug controller interface: normalized stick movement and normal A button presses. The notes-only navigator then approached observed actors, advanced MarioTalk with A, and supplied jump presses when enabled. No memory, actor transform, nerve, flag or switch writes were used.

Computer Use used the installed skill via node_repl and @oai/sky. The existing app window was raised, and ordinary X presses triggered MarioMagic. Grounded spins near the first cage did not break it; jump plus spin did, followed by the remaining cages. The final X after Luma dialogue started the actual SuperSpinDriver ShootStart/Shoot sequence. Screenshots are original JPEG bytes copied before process termination; filenames describe capture intent, not independent proof of completed flight.

The game exited with SIGSEGV before flight completion. launch-flight.jpg shows the launch preparation at the tower, not a successfully traversed flight. first-launch.jpg shows the Luma dialogue before firing.
