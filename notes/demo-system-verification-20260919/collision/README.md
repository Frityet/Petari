## Confirmed divergences and their effects

1. **Moving-surface reaction was discarded (high).** The previous `GameMapCollisionCompat.cpp` routed ordinary and moving-reaction sphere APIs to one host `store_sphere_contacts` path. `StageCollisionService.cpp:1299` returns a zero moving reaction. Original Binder defaults its moving-query flag on, calls `checkStrikeBallToMapWithMovingReaction` in `Game/LiveActor/Binder.cpp:217`, and consumes `HitInfo::_7C` during correction. The restored `OriginalCollisionPartsCompat.cpp:269` preserves the original previous/current-matrix sweep, normal rejection, early encounter, and projected displacement.
2. **Every contact was labeled a face (high).** The removed host adapter assigned `HitInfo::_88 = 1`. Original `MarioCollision.cpp:1384` distinguishes edges and vertices and uses `_88 - 1` to choose an edge normal. The restored KCL/Parts chain retains all seven retail feature values. No claim is made that a particular observed rabbit-route failure resulted from this mismatch.
3. **Contact order and candidate capacity changed (medium).** Host contacts were sorted by global prism identity (`StageCollisionService.cpp:1311`), while original Keeper/Parts/KCL preserve zone, part, and octree-leaf encounter order. Original per-part candidate capacity is consumed before triangle filtering. The restored chain keeps these rules and the original 32-hit keeper limit.
4. **Uniform scale changed the file-thickness threshold (medium).** Host geometry transforms file thickness by model scale (`StageCollisionService.cpp:721`); original Parts converts query radius to local units and KCL uses file thickness times inverse scale, then converts penetration back. A scale-two fixture with file thickness two and world penetration three must be rejected. Explicit thickness four accepts it.
5. **Translated triangle vertices were wrong (high).** Current canonical and native `Triangle::fillData` used scale/rotation-only transforms for positions. Retail evidence in `notes/movement-collision-20260903T034405Z/README.md` identifies the three calls to `TMatrix34::mult` at the real function, and that helper includes translation. Restored canonical code first, then the three native vertex calls (`HitInfoCompat.cpp:348`). Normal transforms stay scale/rotation-only.
6. **Canonical thickness narrow phase had regressed (medium).** Comparing the exact whole-file hash from the prior retail proof found that current `KCHitSphereWithThickness` had acquired ordinary sphere edge/vertex rejects and lost its distinct backside cross-section test. Restored both narrow-phase functions and both traversals from the exact previously verified historical source, rather than treating current donor contents as automatically correct.
