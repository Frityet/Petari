# Platform/resources audit, 2026-09-25

All 91 scoped files (23,222 lines) were read. Every recorded SHA-256 still matched the supplied scope when the JSON was written. The 11,618 lines of generated CP932 mapping/table were reviewed by their consumer and complete table comparison: all 9,280 entries are sorted, unique, identical between TSV/header, and match canonical CP932 encoding. No build or runtime test was run for this audit.

`platform-resources-audit.json` records a destination, deletion dependencies, evidence, confidence and priority for every file. Its `keep-general` disposition describes semantics to preserve, **never permission to keep a compat path**. All final compat path states are `deleted`. Destinations are actual Game, JSystem, NW4R, MSL or Aurora owners; some proposed native SDK ownership files need creation. This is not a directory rename.

## Ranked work

1. **Restore newly recovered original story methods.** `StorySequencePlatformCompat.cpp:71` still throws for dynamic demo construction, but `decomp/src/Game/System/StorySequenceExecutor.cpp:1222` has the complete recovered array insertion. `StaffRoll::startInfo`, `isPauseOrEnd`, and `MR::getStaffRoll` are also complete at donor lines 306, 310, and 696. Restore the original owners and required scene-object closure; copying stubs into Game does not implement those operations. The file's flag helpers belong in GameDataFunction and its unsigned-byte hash in HashUtil.

2. **Delete the production-orphan stage catalog.** `StageResourceBinding.{cpp,hpp}` has no external reference under `src/`: its constructor/type/query matches are all self-definitions. Four tests still instantiate it: OriginalCollisionPartsOwnerTests, OriginalNamePosOwnerTests, OriginalCameraHolderTests and StageCameraResourceTests. The helper duplicates original `Game/Scene/StageDataHolder` start/path/general-position recursion and BCAM/CANM loading. Remove inert fixtures and rewrite relevant resource tests against the actual original owner, then delete these two files without a successor service.

3. **Consolidate the canonical SDK batch.** `JKRDisposerCompat.cpp`, `JSUListCompat.cpp`, and `compat/jaudio/{JAISoundChild,JAISoundHandles,JAISoundStarter,JAIStreamDataMgr,JASSoundParams}.cpp` are byte-identical to the merged donors. `JUTNameTab` differs only in null/cast spelling. `JKRFileFinder` needs its existing empty native base-destructor definition. `JAISound` needs its native-safe `%p` diagnostic; `JAIStream` and `JAIStreamMgr` need their `uintptr_t` ARAM address casts. Add canonical build entries and remove old providers in the same change. JAIAudible and JAIAudience were subsequently assigned to this batch; both are also byte-identical donors and are outside this lane's initial 91-file count.

4. **Return simple MR utility slices to their existing source owners.** MemoryHeapScopeCompat and most MemoryUtilCompat belong in `Game/Util/MemoryUtil.cpp`; OriginalStationedArchiveUtil splits between MemoryUtil and SystemUtil. OriginalLayoutResourceUtil's five font functions actually come from `SystemUtil.cpp:44`, despite the filename. Coordinate these partial providers so consolidation neither drops nor duplicates symbols. Guest execution scopes in OriginalFunctionAsyncUtil must remain until the actual executor/SDK entry boundary provides them.

5. **Remove the mixed forced-include umbrella.** MetrowerksStdCompat imports Game gravity/collision headers, supplies Game overloads, and globally rewrites `DUMMY(...)` function definitions. Put missing includes and LP64 Game fixes into their exact owning files; put generic new, math, macros, legacy STL and printf contracts in JKernel/MSL/SDK headers. Preserve first-declaration printf alias ordering on Darwin and keep the formatter implementation outside its own alias redirection.

6. **Reunite resources with original owners.** OriginalStationedResourceManager replaces the original catalog with ResourceHolderService. ResourceHolderCompat has indispensable native payload/heap lifetimes, but also duplicates Game resource-kind and catalog policy and manually destroys original holder children. Restore the original manager as catalog authority, attach required native lifetime to ResourceHolder/LayoutHolder, and move generic format decoding into SDK loaders. Preserve archive cache alias restoration, material-before-animation destruction and mutex unwinding. Both current and donor `createAndAdd`/`createAndAddLayoutHolder` ignore the heap parameter; this alone is **not** a divergence.

7. **Remove audio-specific substitute policy from compat.** AudioFacadeCompat implements multiple Game classes, a parallel global BGM manager, RuntimeContext synchronization, and many hard-fail sequence/rhythm methods. DisabledObjectAudioService lives in an Aurora namespace but owns Game AudSoundObject/AudSceneMgr/controllers and validates Galaxy's `{14,2,1}` sound-name groups. Those decisions belong to AudSystem/AudSystemWrapper and their actual Game owners. Generic JAI/JAS handles, stream scheduling, decoded PCM and output-device code belong to canonical JSystem/Aurora. Audio can remain deliberately disabled, but that policy needs one explicit Game owner rather than scattered empty functions.

8. **Delete the two-sound modifier table after original recovery.** JAudioSoundParameterSemantics supports only `0x0006001a` and `0x0006001b`; unknown IDs are rejected. The actual policy belongs in `AudSoundObject::modifySe_Kawamura/Takezawa/Gohara`. The merged donor has their callers but not all implementations, so this requires recovery under the decomp guide, not a guessed default. Game-specific pool sizes in JaiStreamPlayback (3 streams, 160 children, 36 blocks) similarly belong to AudSystem configuration.

9. **Consolidate necessary platform support without losing native correctness.** JKR allocation provenance, aligned global new, finalizers and native pointer-width heap algorithms are real general support. Put them with JKernel; remove their reverse dependency on Game mutex/current-heap wrappers and move the Game MEM2 reservation budget back to HeapMemoryWatcher. CP932 conversion belongs to shared encoding support. NAND/SC symbols belong to Aurora; separate `NANDManager::~NANDManager` and Game save-container translation from generic storage APIs. NW4R font resource ownership belongs with the canonical Font/ResFont sources.

## Boundaries

- No scoped source was classified as disposable merely because it is named compat, original, disabled, or platform. The orphan decision was backed by the current production reference scan.
- Preserve authored Game sound IDs, resource paths, format-specific constants and original behaviors such as JAIStreamMgr returning false despite handle attachment. Their presence is not itself evidence of a workaround.
- The audit proves source ownership and specific duplicate/replacement patterns. It does not prove gameplay, save compatibility, SDK accuracy or audio output. Existing focused tests should be rerun by the parent after each coherent implementation batch.
- The separately requested SDK consolidation is documented in `platform-sdk-consolidation.md`; it is not represented as audit-only work.
