# General GX scissor offset and full EFB backing

Implemented the original GXSetScissorBoxOffset BP register 0x59 write (10-bit half-pixel offsets with the SDK 342 bias) and enabled its normal GX initialization. BP decode now updates both scissor and viewport consistently. The resolver enumerates 1024-pixel wrapped ranges, selecting the intersecting rectangle with greatest viewport area then total area, following Dolphin BPFunctions behavior. No game-specific offset or blur branch exists in Aurora.

While VI is active, its renderer publication includes the complete 640x528 EFB (or larger configured native geometry). The main color/depth targets retain unscanned rows/columns at the configured framebuffer scale; ordinary GX texture copies can address these rows. Visible output still uses the actual original XFB copy selected by VI. Without VI, existing direct presentation remains unchanged; native viewport policy keeps physical pixel sizing. Offscreen framebuffer extensions retain their explicit size.

VI geometry publication uses atomics instead of acquiring the guest CPU in the renderer/FIFO decoder. VI activation/shutdown and viewport-policy changes request target reevaluation. Same-size window resize events now reach the actual physical EFB-size comparison. Recorder state replays the resolved scissor/viewport each frame. Depth snapshots capture full-EFB extent at recording time rather than incorrectly scaling the hidden rows into the visible snapshot; see efb-depth/README.md.

Original FullScreenBlur draws its small current-image region into EFB rows 464..527 through the normal wrapped scissor offset, then captures the original player's existing 128x64 texture from y 464. This now uses the canonical Game implementation instead of an alternate offscreen-framebuffer blur algorithm. No new test suite or visual fixture was added. App build and 120-frame fresh-save smoke passed; blur pixels, wrap combinations and all backend policies were not separately validated.

References inspected: local decomp/src/RVL_SDK/gx/GXTransform.c GXSetScissorBoxOffset; local dolphin/Source/Core/VideoCommon/BPFunctions.cpp scissor range selection. Dawn viewport bound handling was cross-checked against its primary source: https://raw.githubusercontent.com/google/dawn/main/src/dawn/native/RenderPassEncoder.cpp (APISetViewport). The viewport may extend beyond the color attachment; the scissor remains clipped to actual EFB backing.
