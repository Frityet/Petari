# Native cursor visibility

The host window opts in to Aurora's `hideSystemCursor` policy. After normal SDL event polling, Aurora hides the system cursor only when the primary window has both keyboard and mouse focus and is neither hidden nor minimized. Mouse leave, focus loss, hiding, and minimization restore visibility through the same policy. Window destruction explicitly restores any cursor hidden by this owner before destroying SDL resources. Policy changes call SDL only on a visibility transition.

The game retains its normal absolute mouse events and star-pointer rendering. No Game files, Wii pointer validity, SDL mouse coordinates, confinement, or relative mode are changed. ImGui's SDL3 backend normally calls SDL_ShowCursor every frame, so this opt-in also sets `ImGuiConfigFlags_NoMouseCursorChange`, handing system cursor ownership to the window lifecycle. Existing debug freecam retains its separate relative-mode enable/disable behavior in RuntimeContext; this change neither invokes nor replaces it.
