Existing `src/Game/xmake.lua` recursively includes Game source and headers, so adding an explicit second build input would be redundant. The parent owns the ordinary factory rows and the general UniquePlanetCreator type registration.

No new rotator, collision, animation or sound algorithm was needed. Existing original MapObjActor initialization/control, MapObjActorInitInfo, MapPartsFunction, MapPartsRotator and MapPartsUtil providers supply the shared chain. `linked-providers.txt` records actual native definitions, not just declarations. All five original archives contain model, KCL and PA resources; four also contain BTK. Fresh hashes of the cached disc-extracted archives match their recorded extraction hashes (`asset-inventory.json`). No generated geometry or fallback model was added.

The original rotator multiplies raw speed by 0.01, then advances once through MapObjActor::control → MapPartsFunction::movement. Its matrix rotates around the corresponding column of the original world placement basis and concatenates the original basis. Original LiveActor animation updates publish that model matrix to CollisionParts; no second map-function scheduler entry is appropriate. Original clipping and demo movement suspension can prevent updates. These facts constrain the test: a clipped or paused opening sample cannot establish that rotation is broken.

Earlier read-only metadata contains local SW_APPEAR=1 on the three Inside rows. **This does not establish that those actors stay dead in the running opening.** The parent's actual registration smoke has all five rotating actors alive at frames 40, 120 and 350, with Middle objects clipped and Inside objects unclipped; their actor nerve is still at -1 during this paused opening interval. MapObjActor::initialize uses the actual appearance switch and original watcher/demo owners. The new probe reads their current state and reports it without forcing appearance or requiring the earlier off-switch assumption. The original StageEffect table has sounds for all five objects and is preserved.
