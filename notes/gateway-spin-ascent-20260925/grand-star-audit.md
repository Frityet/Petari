## Confirmed fidelity differences and applied fix

The initial patch changed only `src/Game/MapObj/PowerStar.cpp` and `src/Game/System/StorySequenceExecutor.cpp`. Both were clean before this lane. The separately authorized player follow-up changes two additional sources described below, also initially clean.

1. **Waiting/revival rotation:** `PowerStar::processWait` at565 dropped `+ val`, merely wrapping the existing rotation. Restored exact donor expression `MR::repeat(mRotation.y + val, 0.0f, 360.0f)` (donor572). This restores ordinary and weak-to-wait spin; it was a visual/state drift, not a proven pickup blocker.
2. **Appearance trajectory:** `PowerStar::exeAppearDemoMove` at634 wrote `vec.lerp(mAppearPosition, mPosition, step)` instead of donor's `mPosition.lerp(vec, mAppearPosition, step)` (donor641). Current JGeometry's three-argument lerp writes to `this`, so the old code left the main position un-interpolated and then accumulated the arc offset onto it. Restored the donor destination. This is the general rise/move appearance path, not the Gateway cage's WeakToWait path.
3. **Koopa appearance lifecycle:** `PowerStar::exeAppearDemoKoopa` had `kill` at appearance start and `appear` at completion, opposite donor. Restored `appear` at695 and `kill` at731. The dead demo model could fail to advance its animation and prevent the stopped-BCK exit. This is a real general lifecycle defect but is outside the Gateway route.
4. **Story sequence scans:** current `isNeedMoviePlayerExecutingEventEnum` and `hasNextDemo` only examined each queued sequence's first command. The donor walks commands to type12/13; `hasNextDemo` additionally skips the current command in sequence0. Restored both exact donor bodies and their small anonymous `isDemoSequenceEnd` helper (current507–553; donor506–546). The previous implementation could miss a later movie or count the current demo as a future demo. Callers are GameScene movie-resource creation and StarReturnDemoStarter's result continuation. GrandStarReturnDemoStarter does not call `hasNextDemo`, and the first Grand Star sequence has no movie command, so these query defects are not claimed as a direct blocker for this first-clear route.

Native architecture, CP932 literals, lifetime, and debug changes remain intact. Equivalent `repeatDegree(value)` calls elsewhere were retained: the current helper delegates to `repeat(value,0,360)`.
