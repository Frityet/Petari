# Original shadow controller ownership on the native port

The Game ShadowController/List/Holder and ShadowDrawer files are copied from decomp after the retail recovery in a2d7a36b9. The native bridge owns the actual original list and controllers in the active SceneObjHolderBinding Game allocation domain. Metadata no longer answers live gravity, collision, validity or visibility queries; the original objects do. Names remain stable decoded host strings. Shape descriptions remain retained metadata; shape-specific GPU drawers are not activated by this checkpoint, and no shadow rendering claim is made.

Native ownership containers, strings and resource parsing explicitly escape Game allocation scopes. Original allocations re-enter their real Game heap. Retirement removes both global and pending holder pointers while the holder identity is registered; a NameObj generation check covers holder-before-actor destruction and address reuse. Replacement constructs a complete new controller graph before retiring the old graph. Empty lists do not construct the global holder. Joint-matrix retirement invalidates the controller before clearing raw matrix bindings.

LiveActor movement now calls the original shadow request. MR resetPosition once again clears the original sensor and binder state, recomputes gravity and animation, resets collision matrices, and requests appearance projection through the original helpers. Runtime shadow setters and LOD visibility changes now target the original typed objects. The obsolete aggregate metadata flags were removed.

The former optional-resource CSV test was migrated to OriginalShadowControllerOwnerTests and its old target was removed. The new fixture requires SMGPC_REAL_DISC and real RuntimeContext/SceneObj/heap owners. It preserves all CSV/model/resource checks and adds typed allocation/name identity, pointer direction setters, one-shot counters, queue deduplication, failed replacement and retirement across two scene generations, including a controller surviving its holder. Calls run under a Game allocation scope. OriginalCollisionPartsOwnerTests now also exercises original shadow projection against an actual archived KCL surface and sensor.

Validation so far: six changed native production/test translation units pass isolated LLVM23 syntax compilation. The coordinated common/game archive build and full main compilation now pass. These fixtures have not linked or run yet because the main owner graph still lacks five scene-transition functions. Fresh Layout, Pointer, J2D and full retail-audio fixtures pass; those results do not establish shadow projection or gameplay. Prior code review is in independent-lifetime-review.md; its inactive matrix issue has now been addressed with invalidation. No jumping, full-camera runtime or demo success is claimed.
