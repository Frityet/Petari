# Original scene draw leaf closure

The first native cohort contains only src/compat/OriginalSceneDrawUtil.cpp: original MR::isDrawSpinDriverPathAtOpa and MR::drawSpiderThreadBloom. It uses the complete original headers supplied by the SceneExecutor import. Both methods retain their original isExistSceneObj guard. Existing real SpinDriverPathDrawInit ownership controls its actual mIsPathAtOpa flag; existing real SpiderThread ownership controls mIsBloomOn and its virtual draw, followed by original Ride opaque buffer draw. No scene owner is constructed or simulated by the wrappers.

Fresh Wii proof is 100% for both functions (68 and 104 bytes), native object compilation passes, and the only direct undefined symbols are the existing SceneObj lookup and CategoryList::drawOpa. See lazy-draw-compile.json, lazy-draw-retail-proof.json and lazy-draw-root-manifest.json. Runtime behavior of present SpinDriver/Spider ownership is not claimed until their complete original construction graph is activated.

A separate active cohort implements the general GX Z-texture API/BP/shader path before restoring original MR::clearZBuffer. The original helper uses a 4x4 Z24X8 tiled texture containing far depth, full-screen quad, color/alpha writes disabled, GX_ZT_REPLACE, and late depth comparison. Aurora GXSetZTexture previously had an empty TODO. Merely copying clearZBuffer would therefore produce incorrect depth. Backend implementation/testing is pending and is not part of the two-wrapper source checkpoint.
