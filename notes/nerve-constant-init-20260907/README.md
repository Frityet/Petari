# Native Nerve constant initialization, 2026-09-07

Activating original Player translation units made unrelated metadata and effect-ownership test links require `MarioActor::exeWait`. The source owner was not missing: the original actor method exists, and MarioJump defines the original ten actor-nerve singleton instances. The native `INIT_NERVE` macro already used C++ inline variables for shared identity across the original ownership boundaries. However, each empty, noinline constructor forced a dynamic initialization root. That retained the otherwise unused singleton, its vtable, and the executor reference.

`src/Game/LiveActor/Nerve.hpp` now gives the seven macros' empty constructors `constexpr` only on TARGET_PC. No constructor has code, fields or instrumentation; only the inherited vptr is initialized. Nerve virtual executor/end bodies, pointer identity and actor state changes remain unchanged. Native inline singleton definitions now follow each macro class definition in the same header or translation unit; INIT_NERVE is empty on native, and INIT_NERVE_NEW delegates its storage to that macro. This makes declaration-header consumers standards-correct and avoids relying on unused inline definitions being emitted from another source file. The Wii constructor expansion retains its original noinline form. The decomp reference header is untouched. This is a native compiler adaptation for the generalized state-machine boundary, not a replacement actor method.

The isolated LLVM23 proof compiles the whole original MarioJump source using current Game flags, including O0 and section GC. Before the change it emitted ten __mod_init_func entries (80 bytes), retaining unused nerve vtables; afterward it emits no __mod_init_func, __cxx_global_var_init or _GLOBAL__sub_I. `proof.py` and its source files reproduce the result. The two-TU executable puts INIT_NERVE calls only in TU A. TU B includes only the macro class declaration header. It also checks an anonymous-namespace nerve and shared singleton addresses, constant construction of all seven macro forms, virtual execute and executeOnEnd, the original empty end callback, NULL behavior, and the existing unavailable exception. It links the real Game Nerve.cpp and Spine.cpp. A declared but undefined unused executor proves the unused singleton can be discarded without a fake implementation. It prints the `[ok] constant Nerve initialization` marker.

`retail-macro-proof.py` preprocesses all original macro forms without TARGET_PC and compares tokens with checkpoint c3d4a5901. All 571 tokens are identical, including the original constructors and singleton declarations. This checks that the native header adaptation does not change the retail macro expansion.

Coordinated root regressions all compile and link successfully after the header change:

- `smg-pc-original-auto-effect-metadata-tests`: passes against the Korean RVZ, processing 2591 records and 612 case-insensitive groups, with capacity, reinitialization, lookup and retirement checks passing.
- `smg-pc-original-direct-draw-texture-tests`: passes, covering 96 independently encoded texels across six tiles, getters, channel order, writing and guards.
- `smg-pc-original-effect-ownership-tests`: link succeeds; the real-disc run reaches Metal initialization then throws `JKR host heap budget is outside the original signed-size range` from its fixture. The effect test owner is addressing this independent runtime fixture issue. No runtime pass is claimed here.

The initial effect runs without SMGPC_REAL_DISC were rejected as expected and are retained separately as *-no-disc.log. The complete build/run results are in regression.json and matching logs. Root build ownership was returned to the effect test agent afterward. No full Gateway chase, player ownership or game-runtime completion follows from these focused checks.

The initial constructor-only draft exposed a second existing issue in the full showcase: inline singleton definitions confined to other source files could disappear entirely when unused there. The class-adjacent definitions fix that declaration-consumer issue. A blanket weak attribute was rejected because anonymous-namespace nerves cannot have weak external linkage. No used/retain attribute or extra global initializer roots the unused executors.
