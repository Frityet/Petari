# RFL exported model API closure

Aurora already implements bounded default-character geometry loading, all requested expression-mask rendering, matrix/normal transforms, and opaque/translucent GX draws in CharacterModel.cpp. The missing eight SDK exports were not missing renderer algorithms: the existing runtime/rfl ABI owner exposed initialization but no draw/transform entry points, and RflService's model initializer always returned NotAvailable.

RFLCharModel now directly owns a unique_ptr to the existing Aurora CharacterModel. Its out-of-line constructor/destructor reside with the complete Aurora model type; no global model registry or alternate publication was added. Successful default-source creation is performed by RflService from its actual validated ResourceArchive and uses the existing Aurora factory under host allocation routing. The original work pointer and request metadata remain recorded. Invalid requests return WrongParam, malformed geometry returns Broken, and unavailable GPU frame/copy capability returns NotAvailable; success is published only after actual model creation succeeds.

The existing runtime/rfl/RVLFaceLib.cpp ABI owner now forwards SetMtx, SetExpression, DrawOpa/Xlu, DrawOpaCore/XluCore and LoadVertex/MaterialSetting to that actual model or shared GX setup. The paired expression getter also reports actual model state. Default draw wrappers use the donor's exact two-TEV default setting from decomp/src/RVLFaceLib/RFL_Model.c. Missing models/settings and unavailable expressions fail explicitly rather than reporting a draw with no geometry. Existing generic rendering algorithms were not duplicated or changed.

MiiFaceParts destructor now deletes its actual owned RFLCharModel, aligned byte buffer, recipe and FixedPosition. Their constructor pointers were already null-initialized; _C8 and _D1 now have safe initial values for partial initialization. No borrowed SceneObjHolder/actor group is deleted.

Limits: only Aurora's existing default-source character factory is connected. Official/controller/middle database model creation and icon rasterization remain unavailable. No live Mii rendering or GPU fixture was run in this lane. This is code integration, not visual correctness evidence. Root owns the integrated app build and bounded smoke; no test cases or build changes were added. All five before/after paths and exact changes are recorded in the manifest and rfl-only.patch. Aurora's unrelated dirty GD headers are untouched.
