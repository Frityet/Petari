# Broad donor import and original factory restoration

Imported all 757 Game C/C++ sources that were missing from the port, preserving every existing native source. Non-ASCII narrow literal groups use the established CP932 API; donor hashes and exact paths are recorded in missing-game-source-imports.json. The previous batch supplied 691 missing Game headers. No new decompilation was performed.

Restored the complete canonical NameObjFactory and ModelChangableObjFactory tables and the actual PlanetMapCreator, including original stage/scenario force-low selection. Deleted the eight alternate scene factory/catalog/area files. Removed all 118 scene-object availability gates and their header so actual original constructors determine dependency closure. PlanetMapCreator owns its parser, row allocations and generated names on the real owner.

Audio output remains disabled under the existing policy. Of the 38 imported audio source units initially excluded, 32 remain inactive and are listed in inactive-audio-sources.json. The actual audience, effector, microphone wrapper and remix owners are now compiled. AudSystem.cpp compiles its original listener operations and explicit unavailable-owner failures on PC; the complete donor DSP/system implementation remains under the non-PC branch. Required native AudSystemWrapper behavior resides in its actual Game/System translation unit, and its compat provider was removed. Its explicit disabled-output query prevents output-only camera, effect, emitter, atmosphere and remix submissions from dereferencing an absent AudSystem. No audio system or listener is fabricated, and remix note-count metadata still requires its real owner. Four AudSystem failures moved from AudioFacadeCompat into AudSystem itself. Other existing audio adapters remain to be removed later.

Early compilation corrections restored donor animation default arguments, actual setEulerX/setEulerY methods, and complete actor declarations. Native pointer alignment/identity checks use pointer-width integers. These are compilation/architecture changes, not scene-specific behavior substitutions. The actors, maps and factory lane notes record exact changes.

After concrete integrated build failures, collect_compile_errors.py collects diagnostics for active imported sources using the current compilation database in one parallel pass. It neither writes objects nor runs fixtures. Integrated build and bounded runtime results are recorded below; imported code alone is not evidence that all actors execute correctly.

The first two diagnostic passes suppressed all diagnostic groups and were only a declaration triage aid: the integrated build subsequently reported required aggregate narrowing diagnostics. The collector now uses -w (warnings only), preserving language errors; pass3 records that corrected pass. Only the full build result is accepted as compilation success.

The first complete compilation reached linking with 134 missing symbols. These were grouped by actual owner rather than collected in a new stub library: complete SpiderThread, SpinDriverPathDrawer, ChipGroup, BlackHole, MercatorTransformCube, OceanSphere and DynamicJointCtrl bodies; missing NPC and general utility methods; and the existing FileSelector/Mii source selection. Eight absent Home Button Menu RSO entry points and its unavailable allocator remain explicit throwing gaps, enumerated in explicit-link-gaps.json.

All missing Game source paths are now present. Screen/THPDraw.c is an imported donor spelling but is not selected because the port already builds its native THPDraw.cpp counterpart. Audio exclusions and the pre-existing unavailable WiiConnect24 worker are retained explicitly.

The DirectDraw 16-bit tile conversion is an intentional general native correction: available retail instructions confirm truncation in the original routine. The native implementation preserves complete halfwords and emits GX byte order. Its evidence and limitation are recorded in texture-tiling/README.md; no pixel-perfect retail equivalence is claimed for that corrected routine.

The final eight link gaps were actual RFL entry points. Those now forward to Aurora's existing CharacterModel drawing/matrix/expression API. RFLCharModel directly owns its native model, and default-source initialization now invokes the real existing creation pipeline. Official/middle-database models remain unavailable. MiiFaceParts releases its owned model, work buffer, recipe and fixed-position allocation. This is build coverage; the opening smoke does not validate Mii rendering.

Validation: build-retry10.log completes the integrated application build in 7.064 seconds (exit 0). The single fresh-save Gateway run completes 120 frames in 2.911 seconds, exits0 and leaves no process; binary SHA-256 is 80156c0eccb3bed71935453db1448f1b0df3f8b6989e47766f7c0ac902af527b before and after.
