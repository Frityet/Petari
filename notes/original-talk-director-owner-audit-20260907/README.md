## Smallest coherent ownership boundary

The scene factory currently returns `smgpc::compat::TalkRuntime`, a NameObj with its own selected/pending/active controllers, BMG flow copies, callback clones, latch state, and presentation record. It also defines TalkMessageCtrl, TalkNodeCtrl, TalkMessageInfo and TalkFunction methods. TalkCompat's createTalkCtrl methods adopt controllers into that owner; ActorRuntimeRegistry retirement releases them through the same owner. These are coupled. Switching only SceneObj_TalkDirector to a genuine TalkDirector leaves controller methods registering into an absent old owner and/or creates duplicate providers.

The original TalkDirector is a LayoutActor registered in the TalkDirector movement category. Its init allocates TalkBalloonHolder, TalkStateHolder, a 128-entry borrowed controller vector, and TalkPeekZ; then initializes Wait nerve, captures all progression branch flags, and appears. Its movement updates holders/controllers first and executes its LayoutActor nerve afterward. Original pauseOff requests movement for the director and all actual balloon/button owners. The current temporary pauseOffTalkDirector wrapper only addresses TalkRuntime and must be retired together with factory/provider migration.

TalkBalloonHolder constructs four ordinary short balloons, event/info/sign/icon balloons, and an IconAButton shared by event/sign balloons. TalkStateHolder constructs one TalkSupportPlayerWatcher, a separate IconAButton, one composition short balloon, and five state objects (short, normal, compose, event, base) with their original shared watcher/button links. Existing SceneObj construction capture and the retained scene Game arena can own these original allocations: registered LayoutActor/NameObj children receive typed retirement; plain state/holder/former records remain in the arena. Preserve these real identities and shared links rather than introducing parallel presentation state. Controller removal during native actor retirement must also remove its borrowed Director vector membership; the current native owned-controller deletion hooks cannot simply disappear.

## Ranked activation blockers

1. **Genuine message-data identity and binary/wide-text storage.** Original TalkNodeCtrl calls MessageSystem::getSceneMessageData and actual MessageData methods. The reference MessageHolder TU already contains constructor, MessageData block parsing, node/branch lookup, and ID-table lookup. Native MessageService/BmgMessageArchive retain real messages and FLW1/FLI1 data, but expose no actual MessageData/MessageHolder. A typed retained resource owner should decode native block fields, nodes/branch indices and text together, preserve original node identity and order, and publish the original getter boundary. Raw Wii BMG casts are invalid on little-endian ARM64; raw DAT1 UTF-16 cannot be exposed as host 32-bit wchar_t. Tag offsets/lengths also require an explicit encoding boundary. Do not point a GameSystemObjHolder member at MessageService or fabricate a reduced GameSystem.

2. **Actual text reveal/tag pipeline.** TalkTextFormer requires getNextMessagePage plus initTagProcessorRecursive, nextStepTagProcessorRecursive and isEndStepTagProcessorRecursive. None has a native provider. The three recursion bodies and their local TextBox lookup are missing from reference and need retail recovery. Original MessageTagSkipTagProcessor::skipTag and MessageEditorMessageTag parameter methods are also absent; TalkNodeCtrl directly requires getParam32. Native BRLYT rendering retains text records and genuine base Pane/Group identities, not actual nw4r::lyt::TextBox-derived objects. The helper must use a genuine TextBox/tag owner tied to the renderer, or a proved native typed boundary; casting the existing base Pane into TextBox would be invalid. Advancing all text instantly would change normal/event talk timing.

3. **Real depth callback registration and ordering.** TalkPeekZ construction dereferences DrawSyncManager::sInstance and registers channel4/count1; capture saves projection/viewport, clears result, emits a breakpoint and GXSetDrawSync token. The current native graph has no manager, setCallback/pushBreakPoint, or GXSetDrawSync provider. Aurora's tagged snapshot/read scope and existing StarPointer native callback lifecycle offer reusable GPU primitives, but are not this original registration owner. Preserve token/FIFO ordering, allocation context, captured camera data, cancellation and callback lifetime. TalkPeekZ's reference float-plus-padding projection/viewport fields also need defined typed storage at the native boundary, like the earlier pointer correction.

4. **Original branch and scene/demo leaves.** Director initialization eagerly queries the whole captured progression flag set (Kinopio/Luigi/Rosetta/green stars/ending); original request/state paths also need real start/endPlayerTalk, NPC camera start/end, YesNoSelector, and canStartDemo providers. The static frontier lists each exact symbol. No camera or progression query may be replaced by a generic false merely to instantiate Director. Existing actual selected-profile storage is the appropriate progression source.

5. **Strict C++ and architecture corrections.** The unmodified Director includes missing revolution/gx/GXGet.h; the real Aurora equivalent is dolphin/gx/GXGet.h. TalkBalloon's private float fmin/fmax helpers collide with libc++ overloads; renaming the local helpers preserves their exact comparison/NaN behavior. TalkState assigns nullptr to two s32 counters and compares a u8 to nullptr; the native expression must be integer zero. TalkMessageCtrl compares bool callback returns to nullptr; use boolean false. Native declarations omit original getMessageID inline and isStageStatePowerStarAppeared; private probes add the exact signatures/body only. Critically, Director::getBranchResult indexes byte offset0x70 from this, which is incorrect after native pointer expansion. Its eventual architecture fix must anchor to actual mIsKinopioExplorerRescued storage and preserve the exact branch IDs, using defined member mapping rather than unchecked pointer arithmetic across bool members.

## Validation and next activation order

`compile-probes.json` records 14 original native/Wii invocations. `adapted-native-probes.json` records five successful private adapted objects; the other two original objects already compiled. `native-archive-frontier.json` subtracts definitions in the seven candidate objects and current Game/common/render/Aurora archives. It is an inventory only: normal platform unwinding/RTTI symbols remain, duplicate TalkRuntime definitions are deliberately not treated as resolved ownership, and archive contents may belong to other in-progress work.

First recover the missing reference tag helpers and test the genuine MessageData resource boundary independently with actual BMG/node/branch/text identity. Then restore the derived text/tag owner and the reusable token-based depth callback mechanism. Only activate the Director/balloon/state/controller cohort and retire TalkRuntime's overlapping providers in one coherent checkpoint, preserving actor-controller retirement hooks. Fixture coverage should include original normal/short/event/compose selection, page reveal/hold/trigger timing, all four short-balloon rotation slots, branch/event callbacks, original pause-off propagation, actor removal and repeated scene retirement. This audit has not linked, run, or rendered that replacement.
