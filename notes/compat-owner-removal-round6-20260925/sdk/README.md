These are original Galaxy overrides. The generic SDK BaseShape donor contains different line/stripe behavior, and therefore is not the correct donor for those callbacks. The current Game donor contains all methods; no decompilation or invented missing body was needed.

The only body addition is the existing `mLastNonzeroUserWork = 0` during emitter initialization. The native pointer-width member and setUserWork tracking already exist in JPAEmitter.hpp; EffectSystemOwnership uses the retained token to retire callbacks of replaced one-shot emitters before destroying their borrowed keeper. Removing its reuse reset would assign a recycled emitter to the previous owner. This batch keeps that lifetime mechanism intact. Existing JPC resource endian decode/retention, pool ownership and Game/Effect teardown remain at their current owners.

All other restored bodies, helpers and tables match the selected donor region exactly modulo whitespace. Explicit FP contraction controls preserve the former three provider flags. Donor TVec::cross calls resolve to the existing general PSVECCrossProduct implementation; donor default MR tolerance is the same 0.001 as the previous explicit arguments.
