# GX Z texture completion

Resumed the interrupted general Aurora depth-texture implementation. `GXSetZTexture` now emits original BP registers F4/F5, and the shared register decoder updates bias/type/operation state for both API calls and binary display lists. The pipeline includes the depth operation, depth type, comparison location and texture-generator count; bias is per-draw uniform state.

The shader consumes the last enabled TEV texture stage's raw, unswapped sample even when its color/alpha inputs do not otherwise use texture data. Z8 selects alpha, Z16 selects red plus alpha shifted by eight, and Z24 selects RGB as a 24-bit word. Bias and optional raster depth addition wrap to 24 bits. Late comparison writes the resulting fragment depth; early comparison retains raster depth while fog still uses the Z texture result. Depth source images use the existing I8, IA8 and RGBA8 tiled decoders, with their original block sizes.

Review references are local Dolphin `Source/Core/VideoBackends/Software/Tev.cpp` (raw last texture, channel packing, addition and 24-bit masking) and `Source/Core/VideoCommon/PixelShaderGen.cpp` (early/late comparison and fog ordering). No game, actor or stage-specific condition was added to Aurora.

The real GPU regression uses tagged depth snapshots and display-copy color readback. It covers 20 single-case combinations, last-of-two texture selection, state changes between draws, depth-only far clear preserving previous color, later farther geometry, late comparison rejection/acceptance opposite to geometric depth, and fog under both early/late comparison. The root target `smg-pc-aurora-z-texture-render-tests` depends only on Aurora libraries. It also has a CMake test in Aurora.
