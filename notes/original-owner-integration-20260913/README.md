# Original process and owner integration

The production `smg-pc --original` route constructs the original GameSystem, original display, file/archive workers, message/font owners, WPad input, sequence controller and real scene owners. Native support borrows those original objects through their actual heap lifetimes; the process does not construct a development RuntimeContext or synthetic StageSession. `--stage NAME --scenario N` requests an ordinary original GameSequence transition once original initialization and scene readiness allow it.

This checkpoint consolidates the previously interdependent pending migrations: original MainLoopFramework/JUT display and ScreenPreserver/J2D support; original layout/TextBox/material/animation/group owners and retained BRLYT/BRLAN/TPL conversion; original Talk and text processing; original Sequence/Event/scene initialization and ScenarioSelect owners; actual pointer/StarPieceDirector and DrawSync callback lifetimes. Replaced proxy implementations are deleted. Original collector, Rosetta, coin and StarPiece group creators use their real classes and authored archive callbacks. Surface, sphere and cylinder shadow drawers use the original geometry and controller projection.

The original process uses mounted in-memory layout holders and the original embedded-font choice during startup. Real scene binding works across the loading worker and main thread, and retains the actual planet catalog, message resources and particle data. All gameplay progress remains in the original controllers, actor nerves, authored placements and save state.
