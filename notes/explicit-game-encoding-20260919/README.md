# Explicit Game string encoding — 2026-09-19

The user explicitly permits this mechanical Game source edit and requested replacing game-literal-preprocessor. UTF-8 source now spells original non-ASCII narrow literals as `CP932("日本語")`, with a leading `compat/Cp932Literal.hpp` include. The macro selects a consteval UTF-8 decoder and frozen Windows CP932 mapping; the result is an inline static const char array with the exact encoded extent. No runtime conversion, allocation, compiler plugin, wrapper, or generated preprocessed Game input is involved. Adjacent literal tokens are wrapped as one expression, preserving their internal spelling/comments/whitespace. Invalid UTF-8 and unmappable characters are compile errors. Existing already-encoded byte escapes stay unwrapped.

The one-time inventory and migration scripts live only in these notes, not in the build. The inventory found no affected narrow character literals, prefixed strings, or mixed high numeric byte escapes; apparent array initializers were pointer tables/struct pointer fields. There are 3580 wrappers across 330 files in the working snapshot, including the newly recovered CollisionArea import. The encoding checkpoint includes 329 previously tracked Game files; CollisionArea belongs to the separate collision checkpoint. Source behavior and surrounding code are untouched. Unwrapping was independently checked against saved pre-migration native bytes using both C++ and Lua normalizers; 330/330 files recover exactly. `migration.json` retains before/after SHA256 values; local full source snapshots need not be duplicated in Git.

The old tracked `script/game_execution_charset.*`, `script/game_literal_preprocessor.cpp` and compilation-database shim are removed. The equivalent untracked migration-era `scripts/build/charset*`, preprocessor and TSV files are removed too. The mapping is now frozen alongside the header, and compilation-database generation simply exports the actual compiler commands. The obsolete Lua converter test/task was removed from the working tree. Unrelated pre-existing Xmake/tooling migration edits are deliberately not staged in this checkpoint; root xmake/README/test-target changes are staged narrowly.

Two native constructors outside Game also now explicitly encode their original names: LightDirector and ShadowSurfaceDrawInit. Host-facing UTF-8 text and inputs to existing runtime encoding functions remain unchanged.
