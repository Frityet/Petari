# Original FurDrawer and shared numeric boundaries

Recovered all six FurDrawer bodies in decomp first from the retained retail FurDrawer.o/assembly. The 0xFC Wii class has three texture owners, five three-float layer parameters, procedural texture controls, and original GX material setup. Wii compiler command and source hashes are retained in this directory. `wii-proof.json` records each fuzzy match: material setup 97.61%, layer setup 99.94%, procedural map 93.22%, interpolation 99.70%, update99%. Constructor86.34% is accounted for by the reference compiler inlining three JUTTexture constructors and update where retail calls them out of line; its initialization and resource writes were compared instruction by instruction. No function is stubbed.

Native source was copied after recovery, with exactly two architecture changes: an Aurora endian header and a packed big-endian16 texture word view. Original generated IA8 byte order is preserved; the raw retail image format is also the format Aurora/Dolphin decode. The Wii constructor's unusual check of its initially-null indirect texture member is retained, as are its untouched layer-start fields and header transparency byte. Neither is silently replaced with guessed behavior.

The existing packed-word boundary moved from compat/BigEndian.hpp to aurora/endian.hpp. It supports unaligned big-endian word reads/writes and a trivial packed word scalar for original CPU-generated buffers. Three existing J3D callers migrated, with the old header removed. An ASan/UBSan proof exhaustively checks all65,536 halfwords, unaligned surrounding-byte preservation,32-bit command reads, and the exact procedural texel byte sequence.

The shared native MathUtil provider now exposes the original floatToFixed16/fixed16ToFloat contract using Aurora's existing Gekko shift and integer conversion primitives. This preserves signed scale at count31, count32 zeroing, count64 wrapping, truncation, halfword low bits, and non-finite results without native C++ undefined conversions. The full math rotation target builds/runs successfully with added fixed-point boundary/round-trip assertions.

The complete original fur owner/shader/drawer cohort is now active in the normal native Game archive, and the full showcase compiles and links. After Aurora gained generalized GX_CLIP_DISABLE polygon support, the actual FurDrawer fixture builds and runs successfully: constructor/resource retention, all four procedural texture passes, layer interpolation, texture matrices, original unlit/lit/indirect GX material commands, and scene heap retirement. See drawer-final-tests.json and the final build/run logs. The separate original FurShader fixture passes all five geometry/displacement cases. Aurora clipping has 73 rendered Metal checks and 256 CPU FIFO/display-list checks passing.

This fixture submits material commands but does not draw a complete fur actor/model. Fresh Gateway integration exposed additional scene lifecycle and collision transform gaps, documented in ../fur-gateway-integration-20260907; no full Gateway gameplay claim is made here. Mario movement and camera remain the next gameplay priority.
