# Player-state conflict resolution, 2026-09-12

Resolved and staged only the 24 assigned conflict paths under `decomp/include/Game/Player/` and `decomp/src/Game/Player/`: Blown, Damage, Faint, FireDamage (header only), Foo, Hang, Rabbit, Recovery, SideStep, Skate, Teresa, Wall, and Press (source only). There is no separate FireDamage source in this cohort, and Press's header was not conflicted. No native source, shared build output, commit, or stash was changed here.

Compared base `d1ae0a05c`, ours `ad4f2b113`, and upstream `cae223c32` using the three index stages. The saved `<family>.<stage>.<extension>` files are the inputs, not additional source providers. `merge-manifest.json` records each resolved source/header hash and the recovered method inventory. Every previously defined named Mario method is retained; the original `NrvMarioActor` initializer cohorts are also retained in each translation unit where ours recovered them. Skate and Rabbit retain their actual out-of-line `notice` definitions.

## Selected upstream corrections and consolidation

- **Faint:** the weak-flip guard reads movement bit 27 (`_1B`), not bit 28 (`_1C`). Retail `doFlipWeak` at `802D97A8` reads word `0x8` and extracts bit 27. Adopted upstream `mTimer`, `mNoDamage`, and `mTookDamage` names and the matching Damage call sites; field offsets remain `0x12`, `0x24`, and `0x25`.
- **Recovery:** special recovery direction uses an angle **greater than or equal to** pi/2. The post-path shadow check only delays the transition when the shadow is **at least 50 units** from the target and more than 300 units from Mario. Both opposite local branch conditions were corrected against the retail instructions. Upstream otherwise preserves the complete path/timer logic. Kept an explicit local gravity reference before virtual `getLastMove`: retail calls gravity at `803092E4` and the actor callback at `803092FC`; source argument evaluation must not make that ordering compiler-dependent.
- **Hang:** adopted the real front eligibility bit `_39` (word `0xC`, bit 25), correct edge selection (edges 0/1 use triangle vertex 0; edge 2 uses vertex 1), complete Triangle assignment, and SDK typed matrix access. Retail constants confirm the upstream update corrections: release displacement -100, movement-direction threshold 0.707, wall-height threshold 45, vertical-speed threshold 160, climb slope angle 5, forward velocity 6, stick threshold 0.95, and opening animation threshold 20 frames. Both back/side eligibility predicates retain retail `!(distance >= 84)` behavior, including the original unordered comparison result. Retail constants are in the original Hang assembly sdata, including `@61318`, `@61695`, `@61698`, `@61699`, `@61704`, `@61705`, and `@61706`.
- **Rabbit:** retained the existing descriptive field names and explicit padding, including `mJumpAnimationIndex` at `0x68`. Incorporated the verified moving/stationary animation mapping only in `impact`. Retail nonzero-stick branch selects pool offsets `0x2C`/`0x3A` (moving A/B); zero-stick selects `0x48`/`0x5A` (jump A/B). The actor Sensor owner was notified to use `mJumpAnimationIndex`, avoiding duplicate field aliases.
- **Skate:** retail starts/probes the acceleration jump, jump 2, and jump 3 animations, and close restores acceleration jump by default, jump 2 for index 1, and jump 3 for index 2. The original archive pool at `805C9398` decodes offset `0x11` as `スケートアクセルジャンプ`, `0x2A` as `スケートジャンプ2`, and `0x3C` as `スケートジャンプ3`. Kept the upstream floor-code enums and shared `exitJump` body.
- **Damage / FireDamage:** adopted the full upstream code with matching Faint field names and real collision-code enums. The after-damage timer must exclude **FireDance (state 9)** and FireRun (state 10); retail `802D6B0C` and `802D6B20` load these values. The old FireDamage (state 8) exclusion was wrong. The rebound-wall factor 5 already existed in both versions and is not a newly fixed behavior.
- **Wall:** adopted upstream raw-byte `u8 isCancel()` return, matching retail `lbz` at the end of the method. Kept upstream typed `_20._28` bit access and ordinary math API use instead of the former translation-unit macro rename around `JMAAcosRadian`.
- **Foo:** adopted complete upstream source and typed `TMtx34f` backing, preserving the actual movement and trail drawing algorithms. The real SDK API and layout replace the raw matrix representation.
- **Blown:** incorporated the upstream timer name and shared vector operation, retained the semantic Recovery enum and all original initialization providers.
- **SideStep:** retained the already recovered body and explicit layout padding, while using the actual typed Triangle matrix API and Hopper enum. All source methods remain present.

## Local evidence retained where upstream regressed or weakened fidelity

- **Hang `tryClimb`:** retail address `805CBB7C` decodes to `つかまりスリップアップ準備`. Upstream incorrectly truncates this to `つかまりスリップアップ`. The resolved source retains the retail name.
- **FireRun `update`:** retained the locally recovered full method. Retail `802D7448`–`802D7454` loads 1, divides it by the duration, then scales the vector by that reciprocal after the speed and remaining-time scales. The explicit recovered expression and callback order preserve this arithmetic sequence.
- **Teresa:** retained the recovered state bodies and the independently verified actor animation behavior from `notes/original-teresa-animation-fidelity-20260907/`. In particular, independent wake-up probes, branch-local/repeated virtual movement calls, gravity-before-movement ordering, and intermediate `_9B0` stores remain intact. Adopted upstream actual `XanimeGroupInfo`/`XanimeBckTable2` tables and typed `_9B8`/`_9BC` owner fields; this removes the private duplicate raw structs and pointer-cast accessor helpers. `initTeresaMarioAnimation` uses those actual types with the same operation order. The `isTeresaAccel` non-inline declaration is retained.
